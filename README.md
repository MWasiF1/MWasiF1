## What I've shipped in production

- **Raast QR Payment on Delivery** — core contributor to integrating Raast, the State Bank of Pakistan's ISO 20022 instant payment rail, into cash-on-delivery collection. Live across 6 cities, sub-3-second settlement confirmation, automated reconciliation that cut collection disputes by ~35%.
- **BNPL & Lending Platform** — end-to-end Buy Now, Pay Later platform with automated eligibility scoring, a Lending Management System, and a Business Wallet serving 1,000+ merchants.
- **Distributed Observability** — structured logging and correlation-ID tracing across 6 microservices using the ELK stack and GELF, cutting incident diagnosis time by ~50%.
- **Event-Driven Notifications** — Firebase Cloud Messaging and WhatsApp Business API pipeline that raised customer engagement by 25%.
- **Spring Boot API Platform** — RESTful APIs with ~30% faster average response times through query optimization, connection pooling, and caching.

## How I build with AI

AI tools are part of how I ship, not a side experiment:

- **AI pair programming** with GitHub Copilot and Cursor to speed up scaffolding, refactors, and boilerplate across Angular, Node.js, and Spring Boot services.
- **LLM-assisted code review** (Claude, ChatGPT, Gemini) to catch edge cases and keep test coverage consistent across services.
- **Engineering judgment first:** in payment systems, AI-generated code still has to pass the same bar for idempotency, concurrency safety, and reconciliation correctness. I write about that line between speed and safety on Medium.
